# Automatic AI Delivery Finalization Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give a failed delivery finalization to the existing Issue Agent exactly once, validate its changes against the human-approved delivery, and either retry finalization automatically, re-enter evidence review, or stop safely.

**Architecture:** Add the durable `FINALIZATION_RECOVERY` lifecycle state and `RECOVER_FINALIZATION` pending operation. Workspace providers own structured failure diagnostics, approved-content fingerprints, and deterministic post-Agent validation. The Runtime owns the one-attempt budget, Agent orchestration, permissions, transitions, and events. Git implements the first recovery-capable provider; Codex implements the first recovery-capable Agent.

**Tech Stack:** TypeScript 6, Zod 4, Vitest 4, SQLite, Git CLI, Codex SDK, React 19

---

- [ ] **Step 4: Implement legal transitions and result helpers**

Add workflow actions:

- `BEGIN_FINALIZATION_RECOVERY`: `FINALIZING -> FINALIZATION_RECOVERY`; `beginFinalizationRecovery()` stores the supplied attempt ID/diagnostic/fingerprint reference and sets attempts to `1` after checking the budget.
- `RETRY_FINALIZATION`: `FINALIZATION_RECOVERY -> FINALIZING` preserves the spent attempt; `FINALIZATION_FAILED -> FINALIZING` is an explicit human retry and resets the budget to `{ automaticAttempts: 0 }`.

Completion removes provider-private fingerprint state during Workspace release while events retain the audit history.

Add `recordFinalizationRecoveryResult(issue, result, validationKind, now)` in `results.ts`; `validationKind` is the Core-owned union `"UNCHANGED" | "CHANGED" | "UNSAFE"`. It records `summary`, then chooses retry, evidence, or failure from that deterministic input. Do not import Module API into Core and do not branch solely on the Agent's `disposition`.
